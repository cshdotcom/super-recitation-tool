# 超级背书工具 (Super Recitation Tool)

一个基于 **AI 的超级背书 / 记忆背诵工具**。粘贴课文、上传图片识别或拍照导入，AI 自动挖空关键词，配合朗读、语音识别打分、AI 出题、AI 督背、思维导图等九大背书工具，帮你高效背诵课文、单词、知识点。

> 界面复刻自主流背书 App：底部抽屉「导入内容」、阅读页挖空圈圈 ⬭、悬浮答案眼睛按钮、九宫格「背书工具」、「更多」四页签设置面板。

## ✨ 功能总览

### 导入内容（四种方式）
- 📄 **文件导入** — 导入 `.txt` 文本
- 📋 **粘贴文本** — 直接粘贴 / 输入课文
- 📷 **拍照识别导入** — 调用浏览器相机拍照，OCR 识别文字
- 🖼 **图片识别导入** — 上传图片，AI (VLM) 识别文字
- ✨ **AI 生成标题** — 一键概括课文标题

### 挖空系统（圈圈 ⬭ / 下划线两种样式）
- **AI 快速挖空** — LLM 智能分析关键点批量挖空
- **规则挖空** — 每隔 N 个词批量挖空
- **模版挖空** — 每句首词 / 数字等模版
- **手动挖空** — 双击词语挖空 / 取消
- **挖空刷** — 按住滑选连续挖空
- **展示挖空** — 悬浮眼睛按钮一键显示 / 隐藏全部答案，点击单个圈圈逐步揭示
- **AI 快速分块** — 按语义把课文切块，逐块背诵
- **涂鸦** — 在课文上自由画笔迹（自动保存到数据库）

### 九大背书工具
| 工具 | 说明 |
|------|------|
| 📢 朗读文本 | AI TTS 朗读全文（7 种音色、语速可调，长文自动分段合成拼接） |
| 📝 AI 出题 | 自动生成填空 / 选择 / 简答练习题 |
| 🎓 AI 督背 | 背书督学对话，逐句引导、检查背诵、指出漏字错字 |
| 🎤 录音背书 | 语音识别 (ASR) 对比原文，打准确率分、找出漏背关键词 |
| 🧠 思维导图 | AI 生成课文结构思维导图（可折叠） |
| 💬 AI 问问 | 对课文的阅读理解问答 |
| 🎧 耳返背书 | 逐句朗读 → 跟读 → 打分的耳返训练 |
| ✍️ 摹写 | 看原文默写，逐句相似度评分 |
| 🎡 轮盘抽背 | 随机抽取一句背诵 |

### 今日计划 & 存储
- 📅 **制定背书计划** — 设定每日目标词数，进度条跟踪今日已背
- 💾 **真实存储** — SQLite + Prisma 持久化（卡片、挖空关键词、涂鸦笔迹、计划、全部设置）
- 📤 **导出数据** — 复制全文 / 导出 TXT / 导出全部数据 JSON 备份 / 一键清空
- ⚙️ **字体设置 / 阅读模式（跟随·日间·夜间）/ 翻页方式（上下·左右）** 全部持久化

### AI 模型可切换
- 默认使用 **z-ai-web-dev-sdk**（LLM / VLM 图片识别 / TTS / ASR）
- 文本类 AI（挖空、出题、督背、分块、思维导图、标题）可在设置中一键切换为 **任意 OpenAI 兼容第三方 API**（自定义 baseURL / apiKey / model）

## 🛠 技术栈

- **框架**: Next.js 16 (App Router) + TypeScript
- **UI**: Tailwind CSS 4 + shadcn/ui + Lucide 图标 + Framer Motion
- **数据库**: Prisma ORM + SQLite
- **AI**: z-ai-web-dev-sdk（LLM / GLM-4.6V 视觉 / TTS / ASR），支持 OpenAI 兼容第三方模型

## 🚀 本地运行

```bash
bun install
bun run db:push   # 初始化 SQLite 数据库
bun run dev       # 启动开发服务器 http://localhost:3000
```

## 📁 目录结构

```
src/
├── app/
│   ├── page.tsx              # 主编排器（首页 / 阅读页）
│   └── api/                  # 后端路由
│       ├── cards/            # 背书卡 CRUD（含涂鸦笔迹、计划、清空）
│       ├── settings/         # 设置读写
│       ├── ocr/              # 图片文字识别 (VLM)
│       ├── chunk/            # AI 快速分块
│       ├── cloze/            # AI 快速挖空
│       ├── title/            # AI 生成标题
│       ├── tts/              # 文字转语音（WAV 分段合成拼接）
│       ├── asr/              # 语音识别
│       ├── chat/             # AI 督背 / AI 问问
│       ├── quiz/             # AI 出题
│       └── mindmap/          # 思维导图
├── components/recitation/    # 全部背书组件（导入抽屉、阅读页、工具九宫格…）
└── lib/                      # Prisma、AI 抽象层、挖空算法、类型
```
